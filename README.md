# Todo App – Frontend

This is the frontend of my Todo App, built using React.js and Vite. I created this project while learning frontend development and understanding how a React application communicates with a backend through APIs.

## 🛠️ Tech Stack

* React.js
* Vite
* JavaScript
* Axios
* CSS

## ✨ Features

* User registration and login.
* Backend API integration using Axios.
* Environment variable configuration using Vite.
* Fast development and build process with Vite.
